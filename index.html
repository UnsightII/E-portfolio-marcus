Term Reflections

Prelim Term Reflection

During the Prelim Term, I was introduced to the fundamentals of Computer Programming 1. The topics covered included basic programming concepts, variables, data types, and control structures. This term was crucial in building my foundation. I learned the importance of understanding core concepts before moving to advanced topics. The hands-on activities and machine problems helped me solidify my understanding of loops, conditionals, and basic algorithms.

Midterm Term Reflection

The Midterm Term deepened my understanding of programming. We explored functions, arrays, and more complex data structures. I realized the power of modular programming and how breaking down problems into smaller functions makes code more maintainable. The midterm project challenged me to apply all the concepts learned so far. I gained confidence in my ability to write clean, organized code and debug issues systematically.

Final Term Reflection

In the Final Term, we tackled advanced topics including object-oriented programming principles, file handling, and project development. This term was about bringing everything together. I worked on a comprehensive final project that integrated all the skills I had developed. The experience taught me that programming is not just about writing code, but about solving problems efficiently and creating solutions that are scalable and maintainable. I am excited to continue my journey in computer science.
